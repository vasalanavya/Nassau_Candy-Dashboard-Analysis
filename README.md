# 🍬 Nassau Candy Distributor – Product Line Profitability and Margin Performance Analysis

## Project Overview

This project focuses on analysing the product profitability and financial performance of Nassau Candy Distributor using Python, Pandas, Plotly, and Streamlit.

The main objective is to identify profitable products, evaluate division-wise performance, analyse cost structures, understand profit contribution, and visualize factory locations and product-to-factory relationships through an interactive dashboard.

## Dashboard Modules

1. **Product Profitability Overview** – Analyses total sales, cost, gross profit, gross margin, and product-level profitability.

2. **Key Performance Indicators (KPIs)** – Measures gross margin, profit per unit, revenue contribution, profit contribution, and margin volatility.

3. **Division Performance Dashboard** – Compares revenue, gross profit, and margin performance across divisions.

4. **Cost vs Margin Diagnostics** – Identifies cost-heavy, margin-poor, loss-making, pricing-review, and healthy products.

5. **Profit Concentration Analysis** – Uses Pareto charts and dependency indicators to identify products contributing significantly to gross profit.

6. **Factory Location Analysis** – Visualizes five factory locations using latitude and longitude coordinates.

7. **Products and Factories Correlation Analysis** – Examines product, division, and factory relationships through interactive tables and charts.

## Project Outcome

The project provides an interactive business analytics dashboard that helps understand product profitability, identify financial risks, evaluate division performance, and explore factory-product relationships.

The analysis supports data-driven decisions related to product pricing, cost management, and profitability improvement.
